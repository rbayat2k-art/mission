# سامانه راهکار — مدیریت عملیات میدانی

نسخه مستقل سرور 2.6.0 برای دامنه `taprasystem.ir` و سرور `62.204.61.18`.

## معماری

- رابط و API: Next.js 16 روی Node.js 22
- دیتابیس: MySQL/MariaDB
- فایل‌ها و رسیدها: دیسک همان سرور در `storage/uploads`
- استقرار: cPanel Application Manager یا PM2 پشت Apache/Nginx
- DNS/CDN: رکوردهای A دامنه اصلی و `www` به IP سرور

این نسخه هیچ وابستگی اجرایی به Cloudflare Workers، D1 یا R2 ندارد. استفاده از هر CDN استاندارد فقط در لایه DNS/Proxy و SSL مجاز است.

## اجرای سریع

```bash
cp .env.example .env
# اطلاعات MySQL را در .env وارد کنید
npm ci
npm run db:migrate
npm run dev
```

آدرس محلی: `http://127.0.0.1:3000`

## ساخت Production

```bash
npm run verify
npm run build
npm start
```

سلامت سرور و دیتابیس از مسیر `/api/health` بررسی می‌شود.

## حساب اولیه

- نام کاربری: `admin`
- رمز عبور: `123123456`

رمز اولیه را بلافاصله بعد از اولین ورود تغییر دهید. اطلاعات حساب اولیه را می‌توان پیش از اولین اجرا از متغیرهای `INITIAL_ADMIN_*` تغییر داد.

راهنمای کامل سرور: [deploy/CPANEL_DEPLOYMENT.md](deploy/CPANEL_DEPLOYMENT.md)

## بررسی کیفیت

```bash
npm run typecheck
npm run lint
npm test
npm audit --audit-level=moderate
```

داده نمایشی وجود ندارد؛ در دیتابیس خالی فقط حساب مدیر اولیه ساخته می‌شود.

در گزارش‌ها، تأخیر هر روز از اولین «شروع فعالیت» بعد از ساعت ۰۸:۳۰ محاسبه می‌شود. برای هر مأموریت نیز زمان در مسیر از «شروع مأموریت» تا «ثبت مقصد» است و زمان واقعی حرکت، توقف و مسافت ثبت‌شده با GPS جداگانه گزارش می‌شوند.

در مأموریت‌های باز، مشاهده شرح وظیفه به‌تنهایی مأموریت را شروع نمی‌کند. کارمند می‌تواند «شروع کار» را ثبت کند یا بدون آن مقصد و نتیجه را ثبت کند. پایان مأموریت بدون شروع ثبت‌شده، ۳ امتیاز کسر می‌کند و دلیل آن در مأموریت، گزارش ممیزی و مرکز یکپارچگی ذخیره می‌شود.
